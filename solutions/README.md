# Solutions

> [!WARNING]
> **Try each task on your own first.** You learn MapReduce by writing the mapper and reducer yourself, getting a test to fail, and working out why. Copying these files makes the tests green, but you will miss what the lab is for, and you will need these ideas for the quiz and the project.
>
> Before you open a solution:
> 1. Read the task's **Stuck?** tips in the main [README](../README.md).
> 2. Run the failing test on its own (for example `python3 -m pytest tests/test_views_per_image.py -x`) and read the error message.
> 3. Ask a classmate or the TA.

If you are still stuck, open **only the task you are stuck on**, read it until you understand each line, then close it and write your own version.
